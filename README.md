
# FixIt AI – Smart Equipment Troubleshooter

## About the Project
FixIt AI is a simple web-based troubleshooting application designed to help users identify common device problems and receive suggested solutions.

Users can select a problem related to their device, and the application provides a diagnosis along with possible troubleshooting steps.

## Problem Statement
Users often face hardware and software issues with electronic devices but may not know how to identify the cause or resolve them. This project aims to provide an easy-to-use platform that helps users identify common problems and find suitable solutions.

## Features
- User-friendly interface
- Select device problems
- Diagnosis of selected problems
- Suggested troubleshooting solutions
- Simple and interactive web application

## Technologies Used
- Python
- Flask
- HTML
- CSS

## How to Run
1. Install Python.
2. Install Flask using:

   pip install flask

3. Run the application:

   python app.py

4. Open your browser and visit:

   http://127.0.0.1:5000

## Project Objective
To develop a simple and accessible troubleshooting system that helps users understand common device problems and provides basic solutions.
